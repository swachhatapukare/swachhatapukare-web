# SwachhataPukare Foundation

Official website and handcrafted marketplace prototype for **SwachhataPukare Foundation** (Jamshedpur, Jharkhand).

## Quick Start

No build steps or dependencies required. Open directly in a browser or run a local static server:

```bash
# Using Python
python -m http.server 8000

# or using Node.js
npx serve .
```

Then visit `http://localhost:8000` (or `http://localhost:3000`).

## Project Pages

- **Home**: `index.html`
- **Shop & Products**: `shop.html`, `product.html`
- **Cart & Checkout**: `cart.html`, `checkout.html`, `order-confirmation.html`, `track.html`
- **Our Work**: `about.html`, `water-hyacinth.html`, `river-cleaning.html`, `solar-power.html`, `sewage-treatment.html`, `tedxbistupur.html`, `gallery.html`
- **Featured**: TEDxBistupur Community Hub and press spotlight (`the pioneer`, `dainik jagran`, `prabhat khabar`).
- **Get Involved**: `donate.html`, `contact.html`, `bulk-enquiry.html`
- **Policies**: `policies.html`

## Configuration

Site settings and catalogue data are located in `assets/js/`:

- **`assets/js/config.js`**: Foundation details, contact info, social links, working hours, and shipping settings.
- **`assets/js/data.js`**: Product catalogue (items, prices, tags, and images).

## Tech Stack

- Clean HTML5, CSS3, and vanilla JavaScript.
- Fully responsive across mobile, tablet, and desktop.
- Zero build tools or external dependencies needed.
